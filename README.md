- `gcsst-logo.png` — GCSST logo

## Free hosting with GitHub Pages
1. Create/sign in to your GitHub account.
2. Create a new public repository named `abdulfasith37.github.io`.
3. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder.
4. Open the repository's Settings → Pages.
5. Under Build and deployment, choose `Deploy from a branch`.
6. Select the `main` branch and `/ (root)`, then save.
7. Your site will be available at `https://abdulfasith37.github.io/`.

The website uses no paid backend. Email and WhatsApp buttons work through the visitor's email/WhatsApp apps.
